# Third-party components

## Microsoft BASIC for 6502 (m6502.asm)

- **Source:** https://github.com/microsoft/BASIC-M6502
- **License:** MIT
- **Copyright:** Copyright (c) Microsoft Corporation
- **Usage:** The BASIC interpreter source has been translated from Microsoft's
  original MACRO-10/CROSS-16 assembler syntax to ca65 (cc65 toolchain) syntax.
  The KIM-1 target configuration (REALIO=1) is used as the base, with custom
  I/O routines for the W65C51 ACIA serial interface.
